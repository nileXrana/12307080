# Notification App Frontend

Frontend UI for the notification system.

## Overview

This folder contains the frontend implementation for:
- Notification display components
- User interface with Material UI
- Real-time notification updates
- User interactions

## Structure

- `components/` - React components
- `pages/` - Page components
- `hooks/` - Custom React hooks
- `utils/` - Utility functions
- `styles/` - Custom styles

## Components

Material UI components used:
- `Alert` - Notification alerts
- `Snackbar` - Temporary notifications
- `Card` - Notification containers
- `Button` - Action buttons
- `IconButton` - Icon buttons for actions
